# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 3.x.x   | :white_check_mark: |
| 2.x.x   | :x:                |

## Reporting a Vulnerability

Please report security vulnerabilities by creating a **private** issue on GitHub (if the repository allows it) or by contacting me via Discord: https://discord.gg/BGZagw3xnz.

I will respond as soon as possible and work with you to understand and fix the issue.
